# روابط تنزيل APK لمرة واحدة

تم إنشاء مشروع Supabase وربطه بلوحة GitHub Pages.

- Project ref: `hauuwbwrgmaaovnmcoug`
- Region: `eu-central-1` (Frankfurt)
- Edge Functions: `create-download-link` و`redeem-download-link`
- صفحة الزبون: `/download.html?code=...`

## الأمان
- مفاتيح الإدارة تحفظ كـ SHA-256 hash في قاعدة البيانات.
- جدول الروابط وجدول مفاتيح الإدارة عليهما RLS مفعّل ولا توجد سياسات للعميل العام؛ الوصول الإداري يتم من Edge Functions باستخدام service role الموجود في بيئة Supabase فقط.
- لا تضع service role key في GitHub أو صفحة الويب.
- الرابط يُستهلك ذرياً عند ضغط الزبون زر «ابدأ التنزيل»؛ الطلب الثاني يُرفض.

## استخدام اللوحة
1. افتح لوحة apps وسجّل دخول GitHub بالطريقة المعتادة.
2. أدخل مفتاح الإدارة في قسم «إعدادات روابط الزبائن لمرة واحدة».
3. بجانب أي APK اضغط «رابط زبون لمرة واحدة».
4. انسخ الرابط الناتج. زر AFTVnews ينسخ الرابط ويفتح موقع AFTVnews.
5. الصق الرابط في AFTVnews للحصول على كود Downloader الرسمي، ثم أرسل الكود للزبون.

ملاحظة: AFTVnews هي التي تصدر الكود الرقمي. لوحة apps تولّد رابطاً خاصاً صالحاً لاستخدام واحد ولا تستطيع إصدار أكواد AFTVnews من داخل خدمتها مباشرة.

## حدود النظام
يُستهلك الرابط عند أول ضغط ناجح على «ابدأ التنزيل»، قبل تحويل المتصفح إلى ملف APK. لا يمكن ضمان اكتمال تنزيل الملف بعد استهلاك الرابط؛ إذا انقطع الاتصال بعد الاستهلاك فأنشئ رابطاً جديداً. ولا يمكن منع مشاركة ملف APK نفسه بعد تنزيله.
